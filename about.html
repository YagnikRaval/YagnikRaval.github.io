Hi — I'm Yagnik. I'm a writer and poet. This site hosts my poems, essays, and creative experiments.

How to add posts

  1. Create a new markdown file in _posts/ named YYYY-MM-DD-your-title.md.
  2. Start the file with YAML front matter (see sample post in _posts/).
  3. Push it to this repository — GitHub Pages will build the site automatically.
